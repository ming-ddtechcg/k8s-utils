Project Plan - EKS Managed Node Group with Classic Load Balancer
================================================================

Based on the existing terraform source codes (*.tf), this project will add the following AWS resources:
- Classic Load Balancer (CLB)
- Target Group (TG)
in a separate terraform file for:
1. create a TG and attached with the all of Auto Scaling Groups (ASGs) that created by the modele "eks" in the terraform resource "eks_managed_node_groups".
2. create a CLB and attached with the Target Group from the above with following requriements:
   - CLB is the public facining.
   - CLB will route to all availbility zones.
   - CLB will be assoicated with the security groups that created by the model "eks", and the security groups have the rules to handle the public inbound ports, 80 and 443.
