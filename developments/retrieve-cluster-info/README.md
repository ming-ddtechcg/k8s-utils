# retrieve-cluster-info
To retrieve the Kubernetes cluster information from configMap/kubeadm-config in the namespace "kube-system" for:

- DNS domain
- pod subnet
- service subnet

The app is able to be executed in:

- outside the kubernetes system.
- inside the pod with the RBAC permission.
