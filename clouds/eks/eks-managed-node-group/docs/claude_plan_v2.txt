Project Plan - EKS Managed Node Group (v2)
=====================================

1. Makefile commands - final behavior:
   - "make init" - runs "terraform init", but only if the ".terraform" directory
     doesn't already exist.
   - "make plan" - runs "make init" first if not yet initialized, then runs
     "terraform plan -out=tfplan". automatically re-plans if any ".tf" file
     changed since the last plan, otherwise reuses the existing "tfplan".
     removes "tfplan" if the plan fails.
   - "make apply" - always makes sure a fresh "tfplan" exists first (via
     "make plan"), then runs "terraform apply tfplan". deletes "tfplan"
     afterwards since state has changed and any prior plan is now stale.
   - "make destroy" - runs "make init" first if needed, then stops with an
     error message if "terraform.tfstate" is missing or no resources are in
     state; otherwise runs "terraform destroy" and removes any stale "tfplan".
2. "make clean" - cleanup target:
   1. runs "make destroy" first, but only if resources are actually deployed.
   2. removes ".terraform", ".terraform.lock.hcl", "terraform.tfstate",
      "terraform.tfstate.backup", and "tfplan".
